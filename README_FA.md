# راهنمای تانل سیمرغ

[English](README.md) · **فارسی**

راهنمای تست‌شده‌ی میدانی و چند اسکریپت کمکی برای راه‌اندازی تانل
[BackPack](https://github.com/AminMGMT/BackPack) بین دو سرور (سرور ورودی
«ایران» و سرور «خارج») و رفع مشکل قطع‌وصل مکرر.

> Based on BackPack by Amin Mohammadi (AminMGMT)
> https://github.com/AminMGMT/BackPack

این مخزن **خود BackPack را شامل نمی‌شود و آن را تغییر نمی‌دهد**. فقط از نسخه‌ی
رسمی و دست‌نخورده‌ی BackPack استفاده می‌کند و مستندات و اسکریپت‌های پوسته اضافه
می‌کند. BackPack تحت مجوز AGPL-3.0 است و نام آن متعلق به نویسنده‌اش است.

---

## ماجرا چه بود؟

تانلی چند هفته درست کار کرد و بعد هر حدود ۱۷ ثانیه قطع می‌شد و کاربران مدام
قطع می‌شدند. کل مسیر عیب‌یابی و راه‌حلی که جواب داد این‌جا ثبت شده تا در حدود
۲۰ دقیقه تکرارش کنید.

**علامت (لاگ کلاینت):**

```
[WARNING] nothing heard from the server for 15s after it had been heartbeating
[INFO] restarting client...
```

**علت (در مورد ما):** ترانسپورت *Reverse TCP* روی آن مسیر شبکه ناپایدار بود.
پینگ، SSH و باز بودن پورت‌ها همه سالم بودند و همین مسئله را گیج‌کننده می‌کرد.
«تست اتصال» داخلی BackPack (گزینه‌ی `0` منو) آن را روشن نشان داد: TCP روی ۸۵٪،
WS روی ۷۷٪ و PCK روی ۶۰ از ۶۰.

**راه‌حل:** رفتن از تانل *Reverse TCP* به تانل لایه‌ی ۳ **Direct PCK** با همان
پورت‌های فوروارد. بعد از آن صفر قطعی، ۰٪ افت بسته و حدود ۷۸ ms.

داستان کامل: [docs/case-study.fa.md](docs/case-study.fa.md)
قدم‌به‌قدم: [docs/howto.fa.md](docs/howto.fa.md)

## شروع سریع

۱. BackPack را روی **هر دو** سرور نصب کنید (نصب‌کننده‌ی رسمی، با کاربر root):

   ```bash
   bash <(curl -fsSL https://raw.githubusercontent.com/AminMGMT/BackPack/main/install.sh)
   ```

   یا اسکریپت همراه این مخزن که همان نصب‌کننده‌ی رسمی را دانلود می‌کند و
   مراحل بعدی را چاپ می‌کند:

   ```bash
   bash scripts/install.sh
   ```

۲. بفهمید مسیر شما واقعاً کدام ترانسپورت را تحمل می‌کند.
   سمت ایران: `sudo backpack` ← `0` ← `1` (Iran) و لینک را کپی کنید.
   سمت خارج: `sudo backpack` ← `0` ← `2` (Kharej) و لینک را بچسبانید.
   حدود ۴ دقیقه صبر کنید و بخش **Works Steadily** را بخوانید.

۳. با بهترین ترانسپورت تانل را بسازید (Setup Iran ← Direct ← PCK، پورت‌هایی که
   می‌خواهید فوروارد شوند را بدهید، سپس لینکی که چاپ می‌شود را روی سرور خارج
   اعمال کنید).

۴. بررسی:

   ```bash
   bash scripts/diagnose.sh          # فقط‌خواندنی، هر زمان امن است
   ```

## اسکریپت‌ها

| اسکریپت | کار | چیزی را تغییر می‌دهد؟ |
|---|---|---|
| `scripts/install.sh` | نصب‌کننده‌ی رسمی BackPack را دانلود و اجرا می‌کند و مراحل بعد را چاپ می‌کند | BackPack را نصب می‌کند |
| `scripts/diagnose.sh` | سرویس‌های تانل، تعداد قطعی‌های اخیر، رابط، پینگ از داخل تانل و پورت‌های در حال گوش دادن را نشان می‌دهد | خیر (فقط‌خواندنی) |
| `scripts/check-ports.sh HOST PORT...` | بررسی می‌کند پورت‌های TCP یک سرور اتصال می‌پذیرند | خیر |
| `scripts/monitor.sh IRAN_IP PORT...` | دسترس‌پذیری آی‌پی سمت ایران (پینگ، پورت‌ها و تانل) را با زمان دقیق و خط‌های `CHANGE` ثبت می‌کند؛ از سرور خارج اجرا شود | فقط لاگ خودش |
| `scripts/install-monitor.sh IRAN_IP PORT...` | `monitor.sh` را به‌صورت تایمر systemd (هر ۵ دقیقه) نصب می‌کند | یک تایمر اضافه می‌کند |

## حمایت از نویسنده

اگر این راهنما وقتتان را نجات داد، می‌توانید با TRX / USDT روی شبکه‌ی
**TRON (TRC-20)** حمایت کنید:

```
TYT5gy4y1UKvU55sMS6u5YeHnsA7raYuo1
```

آدرس را همیشه از شاخه‌ی اصلی همین مخزن کپی کنید و قبل از ارسال، ابتدا و انتهای
آن را مقایسه کنید. حمایت اختیاری است و تراکنش برگشت‌ناپذیر.
