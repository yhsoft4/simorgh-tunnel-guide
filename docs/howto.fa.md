# آموزش: جایگزینی تانل قطع‌وصل‌شونده با Direct PCK

[English](howto.md)

همه‌چیز را با root اجرا کنید. `IRAN` سرور ورودی است که کاربران به آن وصل
می‌شوند و `KHAREJ` سرور خارج است که سرویس‌ها روی آن اجرا می‌شود. نام‌ها مطابق
منوی خود BackPack است.

## ۰. اول پشتیبان بگیرید

روی هر دو سرور:

```bash
tar czf /root/backpack-etc-$(date +%s).tgz /etc/backpack
```

## ۱. مسیر را اندازه بگیرید (تست اتصال)

۱. روی IRAN: `sudo backpack` ← `0` ← `1` (Iran) ← Enter (آی‌پی پیش‌فرض) ← یک
   preset انتخاب کنید (روی VPS بزرگ Turbo، روی VPS یک‌گیگابایتی Balance).
   لینکی مثل `backpack://t....` ظاهر می‌شود. پنجره را باز نگه دارید.
۲. روی KHAREJ: `sudo backpack` ← `0` ← `2` (Kharej) ← لینک را بچسبانید.
۳. حدود ۴ دقیقه صبر کنید. بخش‌های **Works Steadily** و **BEST SETTINGS** را بخوانید.

نکته: منو را داخل `screen` اجرا کنید تا قطع شدن SSH تست را نکشد.

## ۲. تانل قدیمی را متوقف کنید

سرویس تانل قدیمی پورت‌هایی را نگه داشته که تانل جدید لازم دارد.

```bash
# IRAN
systemctl stop backpack-bpt
# KHAREJ
systemctl stop backpack-bpt && systemctl disable backpack-bpt
```

(نام سرویس ممکن است فرق کند؛ `systemctl list-units 'backpack*'` نام واقعی را نشان می‌دهد.)

## ۳. تانل Direct را روی IRAN بسازید

`sudo backpack` ← `1` (Setup Iran) ← `2` (Direct) ← `2` (PCK) ←
آی‌پی KHAREJ ← پورت تانل (پیش‌فرض 9000) ← پورت‌های فوروارد.

فیلد پورت‌های فوروارد لیست جداشده با کاما می‌پذیرد. برای فرستادن یک پورت به
میزبان دیگر از `PORT=HOST:PORT` استفاده کنید:

```
80,8080,8443,3053,2087,2053,8081,8082,8083,2083,443=203.0.113.10:443
```

بعد: نام و توکن را بپذیرید، اگر UDP هم لازم دارید به سؤال *UDP as well as TCP*
جواب `y` بدهید، به FEC جواب `n`، یک preset انتخاب کنید، به تنظیمات پیشرفته `n`،
برای ری‌استارت خودکار `0` و در آخر `Y`. ویزارد یک **لینک راه‌اندازی** و یک
دستور آماده چاپ می‌کند.

## ۴. لینک را روی KHAREJ اعمال کنید

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/AminMGMT/BackPack/main/install.sh) \
  link apply 'backpack://2....'
```

لینک راه‌اندازی را مثل رمز عبور حفظ کنید؛ توکن تانل داخل آن است.

## ۵. بررسی

```bash
bash scripts/diagnose.sh                       # روی هر کدام از سرورها
bash scripts/check-ports.sh IRAN_IP 80 443 2053
ping -c5 10.10.0.2                             # از IRAN، از داخل تانل
```

دنبال این‌ها باشید: رابط `bp0` بالا، صفر اتصال مجدد در چند دقیقه، ۰٪ افت پینگ.

## برگشت

پشتیبان را برگردانید، سپس روی هر دو سرور `systemctl start backpack-bpt` بزنید و
سرویس‌های جدید `backpack-l3-*` را متوقف کنید.

## دسترسی‌هایی که داده‌اید را پاک کنید

اگر برای کمک به کسی (یا یک دستیار) دسترسی SSH داده‌اید، بعد از پایان کار خط او
را از `~/.ssh/authorized_keys` پاک کنید.
